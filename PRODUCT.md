# Product

## Platform

web

## Users

- **Відвідувачі сайту:** українські сім'ї з дітьми, 28–50 років, які живуть «від зарплати до зарплати», не знають, куди йдуть гроші, сваряться через фінанси, не мають подушки безпеки або хочуть відкладати на дітей і пенсію. Три типажі: «Гроші є, але кудись зникають» (молода сім'я), «Хочу, щоб у дитини був старт» (батьки школярів), «А що буде з нами?» (батьки 40+). Заходять переважно з телефона, з недовірою до «фінансових продавців».
- **Аудиторія портфоліо:** потенційні клієнти Любові (вона розробляє сайти-візитівки для експертів), які оцінюють якість її роботи. *(підтверджено: сайт призначений для портфоліо)*

## Product Purpose

Односторінковий лендинг фінансової консультантки для сімей з дітьми. Мета для відвідувача: зрозуміти, що з його грошима не так, повірити експертці й записатися на «Фінансову діагностику сім'ї» (600 грн, 90 хв онлайн). Друга дія — пройти безкоштовний тест «Наскільки фінансово захищена ваша сім'я». Мета для Любові: демо-робота для портфоліо, яка показує рівень розробки сайтів для експертів. Успіх сайту: людина розуміє пропозицію за секунди, довіряє і залишає заявку; портфоліо-глядач бачить сайт, що не схожий на шаблон.

## Positioning

Незалежна консультантка: не продає банківських, страхових чи інвестиційних продуктів і не бере комісій; працює тільки з сім'ями з дітьми; авторський метод «Сімейний фундамент» (5 кроків: Ясність, Домовленість, Захист, Цілі, Капітал); працює з домовленостями в парі, а не лише з таблицями; доступний вхід за 600 грн і прозорі ціни (конкуренти цін не показують).

## Operating Context

Сайт статичний (HTML/CSS/JS без збірки), заявки — форма з трьома режимами відправки (демо / власний проксі / Telegram Bot API для тестів). Розгортається через GitHub (репозиторій websitesky/finance). Розробка ведеться в окремих гілках: `lyubov` — збережена перша версія (для порівняння), `redesign` — нова версія.

## Capabilities and Constraints

- Мова сайту — українська, звертання на «ви», дружній експертний тон, без фінансового жаргону; назви послуг і кнопок мають бути зрозумілі без контексту (наприклад, не «check-up», а «Фінансова діагностика сім'ї»).
- Структура пропозицій: подарунок (таблиця бюджету CSV, чекліст, гайд) → тест → «Фінансова діагностика сім'ї» (600 грн, знижка з 1 200) → «Фінансовий план сім'ї» (3 тарифи: 1 900 / 3 900 / 6 900 грн) → програма «Сімейний капітал» (6 тижнів, 2 900 / 4 900 / 8 900 грн; таймер і лічильник місць з `config.js`) → B2B (від 8 000 грн).
- Працюючі функції, які треба зберегти: тест із 10 питань і результатом у заявку, форма з валідацією й вікном подяки, модальні вікна (тест, чекліст, гайд, оферта, політика), таймер, cookie-банер, випадаючий список «Послуги» в меню, плаваюча кнопка Telegram на телефоні, Schema.org.
- Усі змінні дані (імена, контакти, реквізити, дата старту, місця) живуть у `config.js`.
- Калькулятор цілей свідомо прибрано; повертати без запиту не треба.
- Немає позначок «демо» на самому сайті (Любов позначає «демо-версія» лише в портфоліо).
- Дисклеймер у футері: інформація освітня, не індивідуальна інвестиційна порада; без гарантій доходу.
- Шрифти мають відрізнятися від інших сайтів портфоліо (не Cormorant, Manrope, Montserrat, Inter, Onest, Unbounded, Space Grotesk, Rubik, Nunito Sans, Jost) і від першої версії цього сайту (Geologica).

## Product Principles

1. Спокій і чесність замість тиску: жодних обіцянок доходу, «швидких» схем, фальшивих дефіцитів.
2. Результат клієнта на першому місці: заголовки про його гроші й спокій, а не про регалії експертки.
3. Зрозуміло без контексту: кожна назва й кнопка каже, що людина отримає.
4. Прозорість: ціни видно, послуги розділені на окремі кроки, «подарунок» відрізняється від платного.
5. Мобільне — основний екран: більшість відвідувачів — з телефона.

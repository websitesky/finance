# Ганна Верес — фінансова консультантка для сімей з дітьми

Лендинг експерта: статичний сайт без збірки.

- `index.html` — сторінка
- `styles.css` — стилі (палітра «вишня і золото», шрифт Geologica)
- `script.js` — меню, калькулятор, тест, подарунки, таймер, форма заявки
- `config.js` — контакти, реквізити, дата старту програми, налаштування заявок
- `worker-example.js` — приклад проксі (Cloudflare Worker) для заявок у Telegram
- `assets/` — оптимізовані фото, favicon, Open Graph

Запуск локально: відкрити `index.html` або `python -m http.server`.
